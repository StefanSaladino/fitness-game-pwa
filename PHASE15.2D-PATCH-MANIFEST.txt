Architecture:
- Adds ACCOUNT as a capacity metric scope for Netlify team/account billing.
- Adds a provider-neutral Netlify API adapter for bandwidth, requests, and reserved build/credit usage.
- Adds an authenticated Supabase Edge boundary that independently re-checks ACTIVE platform-admin authorization.
- Stores NETLIFY_ACCESS_TOKEN only as an Edge/server secret; never in the browser bundle.
- Verifies the configured Netlify account and optionally verifies that a configured site belongs to it.
- Returns provider billing metrics as unavailable/null because the current documented Netlify OpenAPI does not expose Account usage insights billing totals.
- Does not scrape the dashboard, infer usage from logs/deploys, hard-code plan limits, or turn missing values into zero.
- Preserves the platform-admin non-disclosure behavior with generic 404 responses for unauthorized callers.
