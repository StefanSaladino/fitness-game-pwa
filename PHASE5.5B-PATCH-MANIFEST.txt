Scope
- Create-group production form
- Join-by-invite production form
- Group setup screen + controller
- Persisted group membership gate after onboarding
- CSS Modules for all new group feature styles
- Component/controller/gate tests
- Roadmap/docs/structural validation updates

No database migration is required.
No .env.local or secrets are included.
No profile-picture implementation is included yet.
No real lifting dashboard/leaderboard implementation is included yet.

Important architecture notes
- New group components do not import Supabase.
- Forms use pure validation only.
- GroupSetupController delegates to useCreateGroup/useJoinGroup.
- GroupGate delegates to useGroups.
- Setup is required only for zero active groups; one-or-more memberships pass through as GroupSummary[].
- New group styling lives only in *.module.css files.
