Workout Game PWA — Phase 5.3A Authentication + Onboarding UI Patch

Scope
-----
- Production sign-in/create-account/forgot-password/email-verification UI
- Password-reset UI migrated to shared components/controller hook
- Auth validation + user-safe error mapping
- Persisted profile gate after session restoration
- Production username/display-name/timezone/weekly-target onboarding UI
- Onboarding controller reloads authoritative profile after atomic RPC completion
- Responsive phone/desktop styling
- Unit/component/controller regression tests
- Roadmap, architecture, validation, README, and changelog updates

Database
--------
No new migration is required for Phase 5.3A.
This patch consumes the Phase 5.1 complete_onboarding(username, display_name, timezone, weekly_target) RPC already applied to hosted Supabase.

Apply
-----
Copy this directory over the root of your existing fitness-game-pwa repository, preserving paths.
Do not replace or commit .env.local.

Validate
--------
npm run typecheck
npm test
npm run build
npm run test:structure
npm run test:e2e

Expected architectural invariants
---------------------------------
- presentation components do not import Supabase
- auth async behavior goes through useAuthActions -> authService
- onboarding async behavior goes through useOnboarding -> onboardingService
- incomplete persisted profile -> onboarding UI
- completed persisted profile -> authenticated shell
- no Nutrition or calorie-tracking feature added
- smartwatch remains a separate future native companion
