PHASE 16.3 VISUAL OVERHAUL PATCH MANIFEST

Apply after the initial Phase 16.3 onboarding/groups patch and weekly-target accessibility fix.

Why this patch exists:
  - the first pass kept the correct behavior but did not visually match the approved proposal;
  - old navy/blue/green-gradient global styling still bled into the experience;
  - the Groups composition remained too generic;
  - the loading experience still looked like legacy scaffolding.

This overhaul changes:
  - shared Top Set theme tokens
  - shared global UI primitive colors/surfaces
  - body/background treatment
  - AppShell mobile page-title support
  - mobile navigation active state -> orange
  - desktop sidebar active state -> orange
  - shell header charcoal/orange treatment
  - new reusable TopSetLoadingScreen
  - session/route/profile loading visuals
  - onboarding image -> approved bench/dumbbell/water photo
  - onboarding spacing/field proportions/copy -> proposal-like composition
  - Groups zero-membership composition -> proposal-like create-or-home flow
  - targeted invitation composition -> proposal-like invitation + no-thanks flow

Still unchanged:
  - Supabase/database/schema/RLS/RPC behavior
  - onboarding persistence contract
  - group service semantics
  - scoring/XP/badges
  - workout/dashboard/progress data hierarchy
  - full Groups member administration (Phase 16.8)
  - roadmap status

After extraction run:
  npm run typecheck
  npx vitest run src/components/layout src/components/feedback src/features/onboarding src/features/groups/components/CreateGroupForm.test.tsx src/features/groups/components/OptionalGroupSetupScreen.test.tsx src/app/App.test.tsx
  npm run dev

Do visual review before the full release gate.
